# Gestión de Inventarios Químicos
Este proyecto de la materia Ingeniería de Software tiene como objetivo desarrollar
un sistema de gestión de inventarios químicos para una empresa.

## Dependencias utilizadas en el proyecto:
- JavaFx:17.0.14
- Spring Boot: 4.0.3
- MySQL Connector: 9.6.0
- Lombok: 1.18.42
- Spring Data JPA: 4.0.3
- Spring Security Crypto: 7.0.3

## Como ejecutar el proyecto:
1. Clonar el repositorio en tu máquina local.
2. Asegurarse de tener Java 17 y MySQL instalados (Links abajo).
3. Crear la base de datos MySQL con el nombre `inventario_quimico` y actualizar las credenciales en el 
archivo `application.properties`.
4. Ejecutar la aplicación desde el archivo `Launcher` utilizando IntellijIdea.
